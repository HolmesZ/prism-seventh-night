# 游戏背景 · 夜海、星核与第七夜

> 这是《棱镜逆流 · 第七夜》的世界观设定。游戏内可在标题页点「世界观」查看精简版。

---

## 一、夜海

夜海没有月亮，也没有岸。

迷航的船只能等一座灯——它悬在黑水之上，被称作**星核**。星核不烧柴，它烧光：灯芯是光，灯油也是光。每一夜，都要有一位守夜人坐进灯里，替它添一盏。

船靠它认路。坐标在，夜海就有方向；坐标熄了，夜海就只是黑。

## 二、黑潮

灯之外是**黑潮**。

它们不派船，只把光磨成子弹，一颗一颗打进灯里，想把这座坐标从夜海上抹掉。被磨碎的光会变成弹幕，弹幕记得来时的路——所以它们总能找到灯。

黑潮一夜比一夜更用力。到了第五夜，它会派出**守卫者**；到了第七夜，守卫者会亲自走进灯里。

## 三、守夜人

守夜人不能还手——她们没有手。

她们只能是**一面镜子**：光撞上来，就原路回去。这是星核唯一允许的武器，因为它不制造光，只归还光。

前六位守夜人一个接一个碎在灯下：

| 序 | 守夜人 | 留下什么 |
| --- | --- | --- |
| 01 | 第一位 | 一条青色光带，缠在第七位左肩 |
| 02 | 第二位 | 一句「别闭眼」 |
| 03 | 第三位 | 碎裂者的弹道图谱 |
| 04 | 第四位 | 长矛蓄力的角度 |
| 05 | 第五位 | 守卫者第一次围城的记录 |
| 06 | 第六位 | 一条粉色光带，缠在第七位右肩 |

## 四、第七夜

轮到**阿镜**。

她不记得自己是怎么被拼起来的，只记得一句话：*把光送回去。*

她的身体是一枚竖立的棱镜，胸口有九点星火——那是七夜剩下的灯油在计数。两条光带不听话，总在她转身的时候甩到前面去，像两位前辈还在替她挡。

她不能开火。她也不想开火。

**第七夜之后**：如果灯还亮着，她会把自己拆成七枚碎片，钉在灯的七个方向上——那是第七夜的尽头，也是下一夜的开头。夜海没有结局，只有下一夜。

## 五、七夜

| 夜 | 名字 | 内容 |
| --- | --- | --- |
| 第一夜 | 灯油见底 | 只有最轻的游光，像有人在试探灯的温度 |
| 第二夜 | 黑潮试探 | 子弹开始学会看着你转弯（瞄准弹） |
| 第三夜 | 碎裂者 | 一颗子弹裂成三颗，像被摔碎的星星 |
| 第四夜 | 长矛 | 蓄力后刺穿盾面，盾角要正对 |
| 第五夜 | 守卫者降临 | 第一次真正的围城，WARDEN 登场 |
| 第六夜 | 余烬如雨 | 碎火贴着灯壁烧，速度快到来不及眨眼 |
| 第七夜 | 最后的归还 | 终夜守卫走进灯里，最后一滴灯油 |

> 通关后进入**无尽守夜**：夜会一直数下去，直到灯熄。

## 六、关键名词

- **星核**：夜海上唯一的坐标，也是玩家要守的东西。游戏里血量＝星核完整度（5 点）。
- **棱镜（阿镜）**：玩家本体。弧形护盾是她的"镜面"，半径 104 px。
- **脉冲**：把贴身的弹幕震开，冷却约 2.6 秒。
- **棱镜新星**：能量满格时的全场减速（0.28×），每 0.82 秒释放一圈归还波。
- **光带**：阿镜肩后两条拖尾，纯装饰，但也是她"记忆点"的来源。
- **碎片**：绿色＝修复星核 1 点，青色＝补充能量。
