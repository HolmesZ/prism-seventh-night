# 设计说明 · 《棱镜逆流 · 第七夜》

## 1. 一句话

一个**只反弹、不攻击**的弹幕游戏：玩家不是在瞄准，而是在**摆姿势**——转好镜面角度，让子弹自己打回去。

## 2. 为什么是这个玩法

赛道要求「一看就会玩」「玩完还想再来一局」。反射玩法同时满足两点：

- **零学习成本**：鼠标往左，盾往左；子弹撞上来就弹回去。不需要记技能、不需要瞄准。
- **高上限**：反弹弹自动追敌，接得越准、连击越高，分数倍率最高 ×4.5。想刷分就要"站位"——易学难精。

## 3. 核心循环（30 秒理解）

```
子弹飞来 → 弧面护盾反弹 → 弹回去的光变成追猎弹 → 击杀得分 + 连击倍率
        → 能量累积 → 满 100 放「棱镜新星」→ 全场 0.28× 慢动作 + 归还波
        → 黑夜清场 → 星核 +1 → 下一夜（更凶）
```

- **失败条件**：星核完整度归零。被打一下 -1，并有短暂无敌闪烁。
- **续航**：每夜清场 +1；绿色碎片 +1；击破守卫者 +2。
- **节奏**：一夜约 40–90 秒；七夜一局约 8–12 分钟。

## 4. 敌人设计（每一夜一个新词）

| 敌人 | 行为 | 教会玩家什么 |
| --- | --- | --- |
| 游光 wisp | 缓慢靠近，直线弹 | 基本反射 |
| 棱镜 prism | 会绕行，扇形弹 | 用移动修正角度 |
| 碎裂者 splitter | 弹丸命中后分裂 | 别在分裂弹里硬接 |
| 长矛 lancer | 蓄力后高速直刺 | 提前转盾，别贴脸 |
| 碎火 ember | 高速贴近自爆式弹幕 | 用脉冲清场 |
| 守卫者 warden | 多阶段 BOSS，环形弹幕 + 光束 | 走位 + 新星节奏 |

## 5. 叙事与玩法的缝合

| 叙事设定 | 玩法对应 |
| --- | --- |
| 守夜人不能还手，只能当镜子 | 玩家没有攻击键，只有反射 |
| 星核靠光维持 | 血量＝星核完整度，每夜清场会"添一盏" |
| 七夜之后还有下一夜 | 通关七夜 → 无尽模式 |
| 前六位守夜人碎在灯下 | 阿镜肩上的两条光带；失败文案「灯芯把她的碎片收进灯里」 |

## 6. 技术实现

- **零依赖**：`index.html` + `styles.css` + `game.js`，无框架、无构建、无外部字体。
- **渲染**：Canvas 2D，DPR 自适应；背景星空 / 网格用离屏 canvas 预渲染；增益精灵（glow）预烘焙成贴图避免每帧 `shadowBlur`。
- **音频**：WebAudio 实时合成（振荡器 + 噪声 + 滤波器），无音频文件；音乐随战斗强度变化。
- **对象池与上限**：粒子上限 620，超出丢弃，保证低端机稳定 60fps。
- **输入**：鼠标 / 键盘 / 双虚拟摇杆三套并行，自动切换 `aimMode`；`pointer: coarse` 自动显示触屏 UI。
- **状态机**：`menu / playing / paused / dying / dead / ending`，结局与失败都在同一帧循环内可恢复。
- **自测**：`?selftest` 会跑一遍反射、键盘瞄准、触控摇杆、新星、治疗、碎片拾取、死亡流程，把结果写进隐藏 `<pre>`，便于回归。
- **性能**：在 1440×900 桌面与 390×844 手机（DPR 3）上均为 60fps。

## 7. 交互与可达性

- 所有按钮可 `Tab` 聚焦，`:focus-visible` 有 2px 青色描边。
- 关键信息（夜数 / 分数 / 星核完整度）同时有图形与 `aria-label`。
- `prefers-reduced-motion` 会关闭所有 DOM 动画。
- 暂停：`Esc` / `P` / 失焦自动暂停（切标签页不会被打死）。
- 静音：`M`；全屏：`F`；操作提示：`H`。
