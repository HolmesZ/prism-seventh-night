# 提交说明 · 1024 切磋大会「游戏」赛道

> 赛道原话：**让人想再玩一局** —— 一句话变出主角，做一局让人想再玩的游戏。

本文件把赛道页面的每一句要求，对照到本作品的具体交付物。

---

## 一、赛道要求 → 交付物对照

### 「交什么」第 1 条：浏览器或手机能直接玩的链接

| 项 | 内容 |
| --- | --- |
| **可玩链接** | `https://<你的用户名>.github.io/prism-seventh-night/` |
| **备用链接** | 直接上传根目录的 `index.html`（单页即可玩，`assets/` 只影响主角卡配图） |
| **备用压缩包** | 整个仓库打包的 `.zip`（未上线时按赛道说明上传） |
| **适配** | 桌面 1440×900 / 1080p、手机 390×844（竖屏摇杆操作）、平板横竖屏 |
| **依赖** | 无。零构建、零 npm、零框架；断网也能玩 |

### 「交什么」第 2 条：从开始到重开能完整玩一局

一局的完整闭环（全部有实现，可现场验证）：

```
标题页 →（首次）序章 3 页 → 第一夜…第七夜 → 每夜结算播报 → 第七夜结算
      → 结局面板（数据 + 无尽入口 / 再走一夜 / 返回标题）
      → 中途失败 → 棱镜碎裂面板（数据 + 再走一夜 / 返回标题）
      → 任意时刻 Esc 暂停 → 继续 / 返回标题
```

- **有明确终点**：七夜剧情模式，第七夜守住即通关，弹出结局面板。
- **不会走进死循环**：第七夜清场后不再生成第八夜，而是进入结局。
- **重开成本低**：失败页 / 结局页都是一键重开，无需刷新页面。
- **进度有留存**：`localStorage` 记录最高分、最远夜数、是否通关。

### 「交什么」第 3 条：操作提示放进游戏

游戏内共有 **4 层**操作提示，无需看文档：

1. **标题页**：`鼠标/←→ 旋转棱镜`、`WASD 移动`、`左键/Space 脉冲`、`右键/E 新星` 四条常驻；手机端显示摇杆说明。
2. **序章第 3 页**：把「怎么守这一夜」和四条操作再讲一遍，作为首次游玩的引导。
3. **战斗中**：进入战斗后底部显示操作提示条（12 秒后自动淡出，按 `H` 或点右上角 `?` 随时唤出）。
4. **情境提示**：能量满格提示「棱镜新星就绪 · 右键/E」；碎片出现提示拾取；每次进入新的一夜播报夜名与目标。

### 「交什么」第 4 条：1 张主角卡（一句话或草图、生成的角色、游戏里的样子）

| 项 | 内容 |
| --- | --- |
| **主角卡（图）** | [`assets/character-card.png`](../assets/character-card.png) —— 1920×1080，一页四格：`01 一句话` → `02 草图` → `03 角色` → `04 游戏里的样子` |
| **源码** | [`docs/character-card.html`](character-card.html)（可再导出） |
| **文字版** | [`docs/CHARACTER-CARD.md`](CHARACTER-CARD.md) |
| **游戏内入口** | 标题页左侧 `00 阿镜 A-JING` 卡片，或 `主角档案` 按钮 —— 玩家在游戏里就能看主角卡 |

### 「交什么」第 5 条：没上线的网页可在提交页直接上传 .html / .zip

仓库根目录的 `index.html` + `styles.css` + `game.js` + `assets/` 即完整可玩包；打包后直接上传即可，无需服务器。

## 二、「评委看什么」→ 我们的回答

| 评委关注 | 本作的做法 |
| --- | --- |
| **一看就会玩** | 只有 4 个操作；移动鼠标就能挡子弹，左键/右键是两个技能；标题页、序章、战斗内三处提示；第一夜只有最弱的「游光」，前 30 秒不会死。 |
| **能完整玩一局** | 七夜有开头、有高潮（第五夜守卫者）、有终点（第七夜终夜守卫）与结局文本；从标题到结局面板全流程可走完，且结局可直接进无尽模式继续玩。 |
| **主角有记忆点** | 阿镜＝竖立的棱镜身躯＋两点青色眼睛＋两条不听话的光带。她不攻击，只「归还」；两条光带分别是第一位与第六位守夜人的残留——一句话讲得清，一眼记得住。 |
| **玩完还想再来一局** | 七夜通关后有「无尽守夜」继续爬分；最高分 / 最远夜数本地留存；失败与通关都是一键重开；每夜节奏 40–90 秒，适合「再来一局」。 |

## 五、给评审的 60 秒试玩路线

1. 打开链接 → 点 **「开始第七夜」**（首次会走 3 页序章，`Esc` 可跳过）。
2. 第一夜：鼠标左右扫，把子弹弹回去；按一次 `Space` 感受脉冲；能量满了按 `E` 看「棱镜新星」慢动作。
3. 一路打到第五夜，见 **WARDEN 守卫者**（顶部血条）。
4. 想快速看结局：地址后加 `?ending` 直接打开结局面板；`?codex` 看主角卡；`?lore` 看世界观；`?scene=boss` 直接打守卫者。
5. 通关后点 **「进入无尽守夜」**，看还能守几夜。
