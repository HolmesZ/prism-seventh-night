PROLOGUE // 序章

星核是夜海上最后一座灯

夜海没有月亮。迷航的船靠它认路：一座悬在黑水上的灯，叫做星核。 灯芯是光，灯油也是光。每一夜，都会有人坐进灯里，替它添一盏。

第七夜，灯油只剩最后一滴。

她叫阿镜

黑潮从灯外涌来，它们不派船，只把光磨成子弹，一颗一颗打进灯里。 守夜人不能还手——她们没有手。她们只能是一面镜子： 任何光撞上来，都会原路回去。

阿镜是第七位守夜人。她的身体是一枚竖立的棱镜，胸口有九点星火， 两侧飘着两条不听话的光带——那是第一位和第六位留下的。

怎么守这一夜

撑过七夜。每一夜，黑潮都会更用力一点。

  • 鼠标 / ← →旋转棱镜，让弧面迎向子弹
  • WASD移动星核，躲开正面冲撞
  • 左键 / Space脉冲：震开身边的光
  • 右键 / E棱镜新星：能量满时让整个星图慢下来

被弹开的子弹会变成追猎敌人的光。你不必开火。

WORLD // 世界观 夜海 · 星核 · 黑潮

01夜海

夜海没有月亮，也没有岸。迷航的船只能在黑暗里等一座灯——它悬在黑水之上，被称作星核。星核不烧柴，它烧光：每一夜，都要有一位守夜人坐进灯里，替它添一盏。

02黑潮

灯之外是黑潮。它们不派船，只把光磨成子弹，一颗一颗打进灯里，想把这座坐标从夜海上抹掉。被磨碎的光会变成弹幕，弹幕会记住来时的路。

03守夜人

守夜人不能还手——她们没有手。她们只能是一面镜子：光撞上来，就原路回去。前六位守夜人一个接一个碎在灯下，只剩两条光带还缠在第七位的肩上。

04第七夜

轮到阿镜。她不记得自己是怎么被拼起来的，只记得一句话：把光送回去。 撑过七夜，灯就还亮着；撑不过，夜海就再没有岸。第七夜之后，她还有很长的夜要守。
